⚠️ Cómo solucionar el GPS

Chrome bloquea el GPS cuando el archivo está en Descargas (content://downloads). Tienes dos soluciones:

✅ OPCIÓN 1 — RECOMENDADA (1 minuto)
1. Abre Chrome en tu celular
2. Ve a: chrome://flags (escríbelo en la barra de dirección)
3. Busca: allow-insecure-localhost → Enable
4. Regresa y recarga el archivo
✅ OPCIÓN 2 — MÁS FÁCIL
Usa Firefox en lugar de Chrome:
1. Instala Firefox desde Play Store
2. Abre el archivo .html con Firefox
3. El GPS funcionará sin problema
✅ OPCIÓN 3 — REGISTRO MANUAL
Usa el odómetro manual de abajo para registrar los km de cada viaje. Es igual de preciso.
